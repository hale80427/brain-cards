微鑽孔加減速參數：用 jerk 控制 PCD 崩刃風險

BLUF

#1201 與 #1205 決定加速度曲線骨架；#1207、#2007、#2008 拉長尺度；#1568 與 #12051 磨掉尖角；#8090 與 #12060 負責多 block 與多軸協調。D0.4 mm PCD 鑽石英時，第一優先是把命令側 jerk 壓低，再用位置偏差、電流峰值、刀具壽命交叉驗證。

問題核心：刀尖吃到的是 jerk

現場情境是 D0.4 mm PCD 鑽頭加工石英，G83 Macro 裡含大量 G01，進給在 F1000 與 F0 之間反覆切換。這種循環的危險點不在單純速度，而在方向反轉與停啟瞬間的加速度斜率。

刀具受力可以先用 F = ma 理解；真正造成脆性 PCD 崩刃的尖峰，常來自 J = da/dt，也就是 jerk。調機目標應先壓 jerk，再談循環時間。

#1201 與 #1205：決定加速度曲線骨架

#1201 G1_acc 控制 G01 的加減速曲線形狀。定時間模式在短線段中容易把速度切換壓得很短，形成尖峰；定斜率模式讓每次加減速按固定斜率建立，對微鑽孔反轉更友善。

#1205 G0bdcc 對應 G00 快速移動。它影響快速退刀、快速接近與換位時的加減速。傳統切換容易產生 0 → 100% → 0 的暴力變化；補間前或多段定斜率可把快速移動的衝擊拆開。

#1207、#2007、#2008：把加速度作用時間拉長

#1207 G1btL 是補間前時間常數，直接拉長加速度作用時間。時間拉長後，同樣速度變化會分散在更長區間，峰值加速度下降。對 D0.4 mm PCD，這是高優先級調整。

#2007 G1tL 屬於 G01 主加減速時間常數，作用方向與 #1207 類似。#2008 G1t1 則提供第二段時間常數，可把反轉尾巴再拉長，降低方向反轉尖峰。

#1568 與 #12051：把尖角磨圓

#1568 SfiltG1 是 soft filter，可視為低通濾波器。它把加速度曲線的尖角磨成圓弧，降低機械共振、位置偏差與振動。建議起點可抓 20–30 ms。

#12051 Jerk_filtG1 直接作用在 J = da/dt。若目標是降低刀尖撞擊力，這個參數最貼近失效機制。建議起點可抓 10–20 ms，並搭配位置偏差與主軸／伺服電流峰值觀察。

#8090 與 #12060：讓多 block 與多軸協調

#8090 SSS 的核心是多 block 連續化。大量 G01 的 Macro 若每個 block 都停一下，再啟動下一段，刀尖會反覆吃到小衝擊。SSS 的目標是讓 A、B、C block 連續流動。

#12060 VblAccPreInt 允許各軸採用不同加速度策略。X 軸可以保留速度，Z 軸可更柔和，避免單軸策略過度激進。微鑽孔的關鍵通常在 Z 軸，因此這個協調器有測試價值。

三組調機方案

  1. 組合 A，最保守：#1201 = 1，#1207 增加，#2007 增加。效果是加速度下降，循環時間可能增加 5–15%，適合作為第一輪驗證。
  2. 組合 B，推薦：#1201 = 1，#1207 增加，#1568 = 20–30 ms，#12051 = 10–20 ms。效果是加速度與 jerk 同時下降，通常是風險與成本最平衡的方案。
  3. 組合 C，微鑽孔專用：#8090 = ON，#12060 = ON，#1201 = 1，#1207 增加，#1568 增加，#12051 增加。效果是 block 連續化、反轉圓滑化、加速度與 jerk 同步變柔。

用量測結果驗證失效機制

你量到的位置偏差為 +49.87 μm 與 -49.74 μm。對 D0.4 mm PCD 來說，50 μm 約為刀徑 12.5%。這已經超出微小誤差範圍，最大嫌疑會指向 Z 軸動態追隨、過衝、反轉衝擊，再連到 PCD 崩裂。

現場優先順序：① #1201 = 1；② #1207 增加；③ #1568 20 ms；④ #12051 10 ms；⑤ #8090 + #12060。每一步只改一小組，再看位置偏差峰值、電流峰值與刀具壽命是否同向改善。

Source: 彥皓提供的 G83 Macro、PCD 微鑽孔與 FANUC 加減速參數整理。
