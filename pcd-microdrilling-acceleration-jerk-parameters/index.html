調機台不是調速度，是調 jerk：伺服參數提升微鑽孔壽命的物理拆解

BLUF

在 D0.4 mm PCD 鑽頭鑽石英、走 G83 啄鑽 macro 帶大量 G01 往復的情境下，崩刃的元兇不是速度，而是 jerk（加加速度，加速度對時間的變化率）。

控制器裡十個伺服參數可拆成四層：#1201 #1205 是骨架，決定曲線形狀；#1206 #1207 #2007 #2008 是尺度，決定加速度大小；#1568 #12051 是磨皮機，磨掉尖角；#8090 #12060 是協調器，讓運動連續化。最高優先是 jerk filter #12051。

尺度層的 #1206 與 #1207 是一對：#1206（G1bF）是補間前最大速度上限、#1207（G1btL）是補間前時間常數，真正決定補間前加速度的不是任一個，而是兩者的比例 a ≈ #1206 ÷ #1207。這個比例，正是判讀客戶「只動了 #1206、#1207」時的鑰匙——也是本文新增第六章專門處理的場景。

一、撞擊力從哪來：往復鑽孔背後的 da/dt

先看刀具實際經歷的運動。D0.4 mm PCD 鑽頭、石英工件、G83 啄鑽 macro、大量 G01 進給，本質上 Z 軸在做這件事：F1000 下扎、退回 F0、再 F1000 下扎、再退回，持續高頻往復。

很多人直覺把崩刃歸咎於切削速度太快。但對 PCD 這種高硬度脆性刀具，真正打崩刀尖的不是速度本身。把力學鏈攤開：作用在刀尖的力是 F = ma，所以加速度 a 才是力的來源。而刀尖真正「感受到」的衝擊，是加速度在瞬間建立與崩解的那一下，也就是 jerk，da/dt。

啄鑽每一次方向反轉，命令端的加速度都會在極短時間內由正翻負，jerk 出現尖峰，衝擊力跟著爆上去。PCD 韌性低、對衝擊敏感，這種反覆的尖峰才是疲勞崩裂的真正載荷。

所以第一優先不是把速度降下來，而是把 jerk 壓下來。

二、加減速曲線的解剖：尖角是怎麼來的

要壓 jerk，得先看懂加減速曲線本身。控制器算出來的速度命令有幾種典型形狀，差別全在「轉角」。

最原始的是梯形速度曲線：速度直線爬升、維持定速、再直線下降。它的加速度是一個方波，開關之間是垂直跳變；而 jerk 在每個轉角是脈衝尖峰，數學上趨近無窮大。這就是命令端撞擊力的來源。

加上 soft filter（#1568）之後，相當於對命令過一道低通濾波器，把加速度方波的垂直轉角磨成斜坡，尖角被削掉。再加上 jerk filter（#12051），等於直接對 jerk 設上限，讓加速度只能以受控斜率爬。這時速度變成平滑的 S 形，加速度變成梯形，jerk 變成有界的方波而非尖峰。

讀法：左右兩欄是「同一段位移」的兩種命令型態。速度看起來差不多，但往下看一層到加速度、再往下到 jerk，差異被放大——撞擊力住在最底層那一格。

三、十個參數的四層架構

把十個參數放進同一個物理模型，會發現它們各司其職，分成四層。理解這個分層，比死記每個參數的數字更接近實際的控制架構。

第一層：骨架——決定加減速曲線的形狀

#1201（G1_acc）控制 G01 的加減速型態。設 0 是定時間加減速，短線段容易在轉角出現尖峰；設 1 是定斜率加減速，所有加減速維持固定斜率。它控制的是 dv/dt 怎麼建立，對微鑽孔非常值得優先測試。

#1205（G0bdcc）控制 G00 快速移動的加減速，管的是快速退刀、接近、換位。設 0 傳統、設 1 補間前加減速、設 2 多段定斜率。它要避免的是 G00 從 0 直接跳到 100% 再跳回 0 的暴力切換，退刀速度越高越重要。

第二層：尺度——決定加速度大小（#1206 與 #1207 是一對主角）

這一層真正的主角，是 #1206（G1bF）與 #1207（G1btL）這一對。依三菱手冊，#1206 是補間前 G01 的最大速度上限——速度命令能爬到的平台高度；#1207 是補間前 G01 的時間常數——速度爬上平台所花的斜坡時間。

關鍵在於：這兩個不能分開看。把速度－時間圖攤開，#1206 是平台高度、#1207 是斜坡時間，而加速度就是斜率：

這個比例越大，補間前加速度越激進，jerk 的源頭就越凶；比例越小，加減速越柔。這解釋了一個現場常見的誤判：把 #1206 設太高，未必是「真的跑到高速度」——對 macro 裡大量短 G01（Z 軸下扎、退回、再下扎），刀根本還沒加速到目標就要反轉，#1206 太高的實際效果是短距離內逼出急加速，反而推高電流峰值、位置偏差與 jerk。

#1206#1207效果適合情境
↑不變速度上限提高、加速度需求增加追節拍，但風險高
↓不變速度上限降低、加速度需求降低降刀尖撞擊
不變↑加減速變柔、jerk 下降微鑽孔優先建議
↑↑維持速度但降斜率折衷方案

同層的 #2007（G1tL）是 G01 主加減速時間常數、#2008（G1t1）是雙段式加減速的第二段時間常數，功能類似——都在拉長加速度的作用時間、直接把 a 降下來，#2008 專門對付方向反轉時的尖峰。

第三層：磨皮機——磨掉尖角

#1568（SfiltG1）是 soft filter，本質是低通濾波器，把加速度的方波轉角磨成斜坡，平滑加速度、降低機械共振與位置偏差，依手冊設定範圍 0 到 200 ms。#12051（Jerk_filtG1）是 jerk filter，直接作用在 J = da/dt 上，把 jerk 由尖峰削成受控斜率，設定範圍 0 到 50 ms。對 PCD 而言，這是整組參數裡最高優先級的一個。

硬約束：依三菱手冊，S 形濾波的有效時間常數等於 #1568 − #12051，所以 #12051 必須小於 #1568，jerk 濾波不可吃掉整段 soft 濾波。實際設定時要守住這條。

第四層：協調器——全局運動連續化

#8090（SSS，Super Smooth Surface）把多個 block 連續化，避免「A 停、B 停、C 停」的逐段停頓，改成 A→B→C 連續流動；macro 裡大量 G01 的情境效果通常很明顯。#12060（VblAccPreInt，可變加速度）允許各軸用不同的加速度策略，例如 X 軸高速、Z 軸柔和，避免單軸過度激進。

四、三種組合方案

把參數組起來用，會形成不同強度的方案。三組由保守到積極，循環時間與保護程度成反向權衡。

五、回到量測：±50 μm 位置偏差說明什麼

先前量到的位置偏差是 +49.87 μm 與 −49.74 μm。這個數值其實很大。對 D0.4 mm 的 PCD 來說，50 μm 約等於刀徑的 12.5%，已經不是微小誤差。

這代表目前最大的嫌疑不是切削力，而是 Z 軸的動態追隨問題：命令端 jerk 太大導致過衝，過衝在方向反轉時變成撞擊，撞擊把 PCD 打崩。這條失效路徑，和先前觀察到的「同條件下壽命差異可達 15 倍以上」是最一致的。

因此若站在現場調機的位置，優先順序會是：

順位動作打的是什麼
①#1201 = 1把曲線骨架改成定斜率
②#1207 ↑拉長時間常數、降加速度
③#1568 = 20 ms磨掉加速度轉角
④#12051 = 10 ms對 jerk 設上限（核心）
⑤#8090 + #12060最後才開全局協調

先把命令側的 jerk 壓下來，然後回頭看位置偏差峰值、電流峰值、刀具壽命三項是不是同步改善。整套調機的邏輯，就是把 F = ma 鏈條最上游的 jerk 先治住。

六、當客戶實際動了 #1206、#1207：怎麼判讀與接手

前五章是「你從零調機」的路線圖。但現場常見另一種情境：客戶已經自己動了 #1206、#1207，你要做的是判讀他在幹嘛、接下來怎麼接。這一章專門處理這個。

讀法分工：第四章的三組合方案 A/B/C 是你主動調機的強度路線；本章的 DOE 矩陣 A/B/C/D 是客戶已動 #1206/#1207 後的對照驗證實驗，兩張表用途不同，別混。判讀客戶動作的核心，就是第二層那條 a ≈ #1206 ÷ #1207——看的不是單一參數調大調小，是這個比例往哪走。

6.1 三階段策略：先治衝擊，再談節拍

第一階段——先降衝擊、不追節拍。設 #1201=1、#1206 ↓ 或維持、#1207 ↑、#1568 ↑、#12051 ↑。因果鏈是：G01 速度上限不過度追高 → 加減速時間拉長 → 加速度斜率變緩 → soft filter 再磨圓 → jerk filter 再降刀尖衝擊。這一階段適用 PCD 鑽頭、石英、壽命從千孔級掉到 60 孔、Z 軸位置偏差已逼近 ±50 μm 的情況。

第二階段——在不增衝擊下追回節拍。若第一階段壽命改善但太慢，再做：#1206 小幅 ↑、#1207 同步 ↑ 或維持較大值、#1568 與 #12051 先別降。核心原則是允許速度稍高，但不要讓 #1206/#1207 的比例快速變大。

第三階段——處理退刀衝擊。退刀若走 G00，設 #1205=1 或 2（呼應第一層骨架的 G00 形狀控制），搭配檢查 G00 退刀速度、反轉位置偏差、Z 軸電流峰值。退刀瞬間電流峰值若很高，#1205 會比 #1206/#1207 更直接命中問題。

守住硬約束：#12051 必須小於 #1568。依三菱手冊，jerk filter 範圍 0 到 50 ms、soft filter 範圍 0 到 200 ms，且 S 形有效時間常數 = #1568 − #12051。

6.3 怎麼看調對沒有

調對的訊號：Z 軸速度回授尖角變圓、電流峰值下降、位置偏差峰值下降、反轉後振盪時間縮短、孔口崩邊降低、刃口微崩減少、刀具壽命上升。

調太軟的訊號：單孔時間增加、退屑節奏變慢、實際 peck 深度節拍改變、孔底停留變長、切屑排出變差，可能反而增加摩擦熱。兩端都要盯，往柔調過頭會從崩刃問題換成排屑與熱的問題。

6.4 不要爭論「調大調小」，要這 6 個數據

客戶若只動了 #1206、#1207，與其在電話裡爭論「調大還是調小」，不如直接要這六個數據：

#要的數據判讀什麼
①②調整前 / 調整後 #1206、#1207算出比例 #1206/#1207 往哪走
③單孔時間節拍變快還變慢
④Z 軸位置偏差峰值動態追隨有沒有改善
⑤Z 軸電流峰值衝擊載荷有沒有下降
⑥刀具壽命最終成效

有這六個，就能判定他到底是在降撞擊還是只是追回節拍。其中最危險的一種組合是 #1206 ↑ 但 #1207 ↓——這讓 #1206/#1207 的比例快速放大，對微鑽孔等於把撞擊推得更高，方向完全相反。判讀的依據永遠回到那個比例，不是單一參數的增減方向。
