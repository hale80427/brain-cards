參數可調解釋器骨架 · 第二例

共振頻率幾乎不動，尖銳度卻差了 8 倍——會咬人的是後者

同一支超音波刀柄掃了十次頻。共振頻率只在 28520 到 28760 Hz 之間動，總共 0.84%；但共振的尖銳度 Q 從 12.774 一路跳到 106.519，差 8.3 倍。這一頁把那件事變成你可以拉的滑桿：Q 越高，驅動頻率只要漂一點點，振幅就掉一大塊。

這一頁是參數可調解釋器骨架的第二個實例，用來檢驗它換一份真讀數材料還套不套得上。骨架本體與失效點清單見 KB-15_parameter-explorer-skeleton.md；首例見 parameter_explorer_example/，那一份用的是合成示範資料。canvas 內零中文，所有中文標籤都在 HTML 層。
