D0.4 PCD 微鑽 G83 伺服 Overshoot 量測與快速下刀點配置

機台：Mitsubishi M80 控制器｜量測工具：NC Analyzer2｜對象：D0.4mm PCD 微鑽、石英深孔 G83 啄鑽｜2026-06-16｜現場量測 + 配置決策，待實驗驗證

BLUF 伺服穩態表現很好（位置偏差只有 5µm），問題集中在「快速進給轉切削進給」那一瞬間的暫態——那一下產生 50µm 的衝過頭（overshoot）並伴隨高頻振盪。只要讓刀尖在這個暫態平息之後、才接觸孔底，就能在穩態下切削。做法就是把「快速下刀點」拉到離孔底夠遠，給暫態足夠的空間與時間消化掉。

一、量測結果（NC Analyzer2 波形）

下圖是 Z 軸快速移動（檔名 Z_G0_196）的伺服回授波形重現。原始波形有速度、電流、位置偏差三條線；此處聚焦主角「位置偏差」（紅）並疊上「速度」（灰）作為觸發對照，把現場翻拍的螢幕重繪成清晰版本。

二、判讀結果

1. 自激振盪

位置偏差和電流同時高頻抖動，是伺服在暫態下進入自激振盪的典型訊號——馬達在「衝過頭→拉回→又過頭」來回。這比一次平滑的衝過頭嚴重，因為它衝很多次。

2. 兩條風險軸，沒有配置安全係數（以舊設定 60µm 計）

（F15 = 250µm/s；緩衝 60µm 走完約 0.24 秒）

維度暫態量測可用窗口安全係數
空間（衝過頭幅度）50µm緩衝 60µm1.2×
時間（安定時間）0.2 秒緩衝走完 0.24 秒1.2×

→ 舊的 60µm 設定，餘裕只有 1.2 倍，等於沒有安全係數。

3. 一個尚未閉合的關鍵問題：振盪是「誰」觸發的？

若由「減速」觸發（高速轉低速那一下）→ 發生在接觸孔底之前，拉開下刀點就能讓它在空切時消化掉 → 延長下刀點有效。

目前的 Z_G0_196 是空跑波形（沒有切削），只證明「減速會激發振盪」，但還沒證明「接觸會不會再激發一次」。

三、建議配置（快速下刀點該設多少）

原則：下刀點距離 = 安全係數 × 衝過頭幅度，臨界值就是 overshoot ≈ 50µm。下圖把三個方案的「危險區（overshoot 可及）」與「安全餘裕」畫在同一把尺上。

下刀點（距孔底）空間餘裕安全係數每啄多花的空切時間
60µm（最早）10µm1.2× ⚠️基準
100µm（現採用）50µm2.0× ✅—
120µm70µm2.4×+0.08 秒/啄
150µm100µm3.0×+0.2 秒/啄

為什麼往保守端設（風險不對稱）：延長下刀點的代價只有「每啄多零點幾秒空切」（空切不傷刀）；但賭輸的代價是「斷一支 PCD 微鑽 + 報廢石英工件 + 挖斷刀」。下檔損失巨大、上檔節省微小 → 該往保守端站。

四、後續做法（與師傅討論的方案 + 風險提醒）

採行方案

  1. 主軸充分暖機，消除熱偏移。→ 正確。同時讓 overshoot 在穩定溫度下量測，數值才可信（overshoot 會隨溫度漂移）。
  2. 快速下刀點設在距孔底 100µm。→ 2× 安全係數，比舊的 60µm 大幅改善。
  3. 快速進給由 F3000 提高到 F4000（因應生產節拍）。

⚠️ 關鍵風險提醒：第 3 點與第 2 點互相拉扯

快速進給提高 → 進入減速時慣性更大 → overshoot 會變大，這會反過來侵蝕第 2 點剛建立起來的 100µm 餘裕。

估法F4000 下的 overshoot 推估100µm 的安全係數
線性（與速度成正比）50 → 約 67µm1.5×
動能（與速度平方成正比）50 → 約 89µm1.1× ⚠️

實際會落在兩者之間，但方向確定是變大。

→ 務必在 F4000 條件下重新量一次 overshoot，不能沿用 50µm。 若重新量到 overshoot 升到 65µm 以上，100µm 的餘裕就掉回 1.5× 以下，下刀點應再拉到 150µm，或重新權衡節拍與 F4000 的必要性。

五、實驗即驗證（這次實驗要回收的數據）

  1. 重量 overshoot：在「暖機後 + F4000」條件下，量新的 overshoot 幅度，回推 100µm 的真實安全係數。
  2. 記 baseline → 比 delta：只改下刀點一個變數（F4000 / F15 / Q0.05 / 轉速不動），記錄「舊設定孔數壽命 → 新設定孔數壽命」「崩邊率」「斷刀情形」。
  3. 判定觸發源：在實際 G83 切削波形上，把「位置偏差振盪起點」對齊「電流開始抬升（＝刀尖接觸材料）的時刻」——
    • 振盪早於接觸 → 減速觸發，延長下刀點方案正確。
    • 振盪與接觸同步或更晚 → 接觸觸發，需改調伺服參數（降入刀速 / 調減速時間常數 / notch 陷波）。
