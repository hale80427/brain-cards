錢怎麼在同一個圈子裡轉

正常情況下，一條營收線在成長，代表市場上有獨立的人願意用自己的錢換這個產品。那是需求訊號。

但如果 A 公司投資 B 公司，B 拿這筆錢買 A 的產品，那麼 A 的帳上會出現營收——而那筆錢是 A 自己出的。淨現金是流出的，會計上卻是成長。

Zitron 指出這件事在兩個層次同時發生。

他認為最能說明問題的是規模比例。已經花掉的錢，跟真正從外面收進來的錢，不在同一個數量級。

他用來推論的那個工具

這些是上市公司。有好消息一定會講。而它們全都不拆分揭露 AI 分項營收。

他的推論是：不講，本身就說明了很多。而偶爾要講的時候，用的是一個叫 annualized run rate（年化執行率）的數字——

它從來沒被定義過。可以是某個月乘以十二，可以是第十三個月，可以是最近四週乘以十三。每次都不一樣，而他們從不定義。 Ed Zitron · 05:44

同一招他用在晶片上：官方講「效率十倍」「每兆瓦更多美元」，就是不講「和客戶一起把單位成本降了多少」。而如果那是真的，那是全世界最容易講的一句話。

你付的二十美元，不是它的價格

需求這個詞在經濟學裡本來就含價格——「在某個價格下的需求量」。脫離價格談需求量，等於拿掉定義的一半。

他引一份分析機構的估算：訂閱制之下，使用者能燒掉的成本遠高於他付的錢。

訂閱方案可燒掉的 token 價值倍率
ChatGPT $200 / 月約 $14,000約 70×
Anthropic $200 / 月約 $8,000約 40×
一般 $20 / 月約 $400約 20×

倍率的大小決定了訊號被扭曲的程度。如果補貼是百分之二十，使用量還帶著偏好資訊。如果是二十倍，使用量跟真實需求之間幾乎沒有可以推論的關係。

而這個實驗真的做過一次

2026 年 3 月左右，OpenAI 把一百五十人以上的企業客戶轉成按 token 實付。他描述的落差是這樣的：

轉換之前，AI 是史上最有生產力的東西、改變了一切。真的要付錢的那一刻，同一批人的第一反應是「我們得把成本降下來」。有一家共乘平台三個月燒完全年的 token 預算。

他因此把「大家都愛用」這個論證，換成一個可以驗證的問題：如果按每百萬 token 的實際價格付費，同一批人還會用同樣多嗎？

他自己給了支持方可以主動取得的證據形式——如果人們每做一件事付三、四塊美金還是很開心，那才是一個論證。

「大家都在用」為什麼不能當證據

主持人的數據很強：ChatGPT 六十天破一億活躍用戶，而同一個里程碑短影音平台花了九個月、照片社群花了兩年半、全球資訊網花了大約七年。

Zitron 不否認這些數字，他攻的是「採用率」這個指標本身。而他指出的兩個扭曲源是各自獨立的——一個降低使用的成本，一個提高不使用的成本。

扭曲源一 · 使用的成本被壓低 補貼讓使用量膨脹，而膨脹的那一部分不含偏好資訊——它只說明便宜的東西大家會多拿。
扭曲源二 · 不使用的代價被提高 功能被預設塞進你本來就要用的軟體，而且在某些公司，不宣稱自己因為 AI 更有生產力是有職業後果的。

他的用詞是「史上規模最大的非自願技術推送」。而他最有力的一句是歷史對照——

你不會看到到處都是文章說，如果你不上網你就會被拋下。也沒有職業上的後果。這在網際網路的時代沒有發生過。 Ed Zitron · 01:26:31

這一段的價值不在於它證明了什麼，而在於它讓一個指標失效。支持方與反對方都在引用採用率，而它現在兩邊都不能用。

這次跟達康泡沫差在哪一格

主持人的框架是標準的：達康泡沫 90% 的東西歸零，但誕生了改變世界的公司。泡沫就是這樣運作的。

Zitron 的反駁不是「這次不會有贏家」。他指出的是資產性質的差異，而這個差異可以拆成三格去查。

當年那個「泡沫後被救回」的故事，主角是暗光纖——以為網路需求每九十天翻倍（實際是六到十二個月），於是大量超建。後來需求真的來了，那些沒被點亮的光纖被接上，成為之後二十年的基礎。

他的問題是：那個結局能不能複製，取決於等待的成本由誰付、每天付多少。

變數暗光纖AI 資料中心
閒置期間的成本趨近於零，埋下去就不再花錢電力、冷卻、維運持續發生
技術折舊速度慢，光纖本身沒有過時快，每一代顯著更好
能不能挪作他用高，任何網路流量都能走低，專為生成式 AI 訓練與推論

這一段的好處是它把「這次跟上次像不像」從印象之爭，變成三個可以真的去查的變數。任何說「這次也會有好結局」的論述，都可以拿這三格去對。

關鍵前提 他攻的是「泡沫後基礎設施會被後續需求救回」這個故事，不是「AI 沒有價值」。這兩件事被混在一起討論時，雙方會各說各話。
邊界條件 三格全部建立在「沒有大幅降低單位推論能耗的突破」這個前提上。他自己也說，硬體突破是會讓他改變想法的條件之一。
待驗證點 舊卡降階承接推論負載、以及 GPU 的第二市場，這兩條路他沒有處理。它們不是理論上不可能，只是目前沒有證據在發生。

他預測的骨牌，以及倒下的順序

他的預測有時間戳，這是它最好的地方——2027 是可以被回頭檢查的。

被問到一般人該怎麼辦時，他說自己手上全是現金，市場是被媒體吹起來的賭場，然後自己收回了一句：「我不太適合給財務建議。」

他真正給的只有一句——不要相信那些承諾，相信他們會說能讓股價跑起來的話，而不是實際在發生的事。

主持人最強的一擊，他沒有回答

Bartlett 提出了一個 Zitron 沒有真正反駁的論證：

在一個人人都能用這些工具的世界，工具能做的事都會被商品化。工具做不到的——人的品味、判斷、人際能力——反而變成最有價值的，因為稀缺與困難在歷史上一直是價值所在。 Steven Bartlett · 01:28:06

他推到寫作上：如果你用 AI 寫社群貼文，它們就會是社群貼文，因為大家都在用同一套。而一篇好貼文現在反而是不用那些工具的人寫的——更深、更私人、有只有一個人才有的親身經歷。

Zitron 的回應是換角度同意：那些人本來就在半吊子做他們的工作，現在只是他們有了半吊子機器。

但他沒有處理「稀缺性會轉移到哪裡」這個問題。而那正是這場對話裡，對個人最有可操作性的一段。

什麼會讓他承認自己錯了

主持人直接問了。他的答案有四條，而最後一條最尖：

  1. 成本要有硬體突破，降到千分之一——「而那沒有在發生，因為他們都在試」
  2. 資料中心的蓋法要改——燃氣渦輪、社區被強加、噪音
  3. 產品要真的能自主做事，要「與魔法無法區分」
  4. 而這個高標準是他們自己訂的

他附帶了一條很尖銳的規則：如果他能監管這些公司，他會禁止他們用未來式講話。只能講今天，最多給兩週的未來。因為如果只能講今天正在發生的事，他們聽起來會像瘋子。

他也主動指出這場對話本身的不對稱——當你是懷疑論者，被放在烤架上的是你，不是那些花了一兆美金的人。
