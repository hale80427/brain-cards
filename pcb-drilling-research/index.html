PCB 鑽孔研究：AI 伺服器的供應鏈瓶頸，藏在一支 0.1mm 鑽針裡

2026-05-28 · 投資分析筆記

BLUF
  • AI 伺服器讓單支鑽針打孔數從 3000+ 孔掉到約 200 孔，高階鍍膜鑽針嚴重供不應求
  • 龍頭仍是日本 Union Tool（佑能工具）——自製設備、塗層技術（ULF 潤滑膜）與 0.08mm 以下超微徑製程
  • 真正卡關不是「鑽得多深」，是 M9 板材 + 多層板 + 機械鑽孔三件事疊在一起的物理極限

為什麼 Union Tool 一直是龍頭

目前 PCB 鑽孔領域（尤其是微型鑽頭），技術與整體實力最強的仍是日本的 Union Tool（佑能工具）。它的護城河有兩層：

  • 自製設備 + 極高製程穩定性：在超微徑（0.08mm 以下）、高深寬比、高階 HDI / IC 載板應用上，品質與壽命仍是業界標竿
  • 塗層與幾何設計：例如 ULF 潤滑膜（Ultra-Low-Friction）這類專屬塗層，加上精密刃口設計，扛得住 AI 伺服器、高層數（28–46 層以上）、硬質板材的嚴苛鑽孔需求

AI 伺服器帶來結構性變化：板層數暴增、板材更硬更厚。

單支鑽針打孔數從過去 3000+ 孔掉到 600 孔左右，最高階板甚至只剩 200 孔。

高階鍍膜鑽針嚴重供不應求，原本就強的高階玩家（Union Tool + 台灣的尖點 Topoint）更吃香。

結論：0.1mm 以下或高難度板材優先選 Union Tool。資料來源：Digitimes 2026-03-09 報導。

三種板子的差別

普通 PCB、HDI、IC 載板常被混為一談，但它們解決的問題完全不同。

類別比喻技術核心
普通 PCB一般電線把家電接起來線粗、空間大，夠用但塞不下太多東西
HDI（高密度互連）極細的線 + 立體高架橋微盲孔（Microvia）、埋孔（Buried Via），孔可只打到某層，不貫穿整塊板
IC 載板晶片與外面世界的精密轉接器ABF 增層膜（Build-up Film）一層一層疊上
  • HDI 讓手機、平板、穿戴又薄又強。同樣大小可以塞進更多零件、走更多路
  • IC 載板直接把 CPU、GPU、記憶體晶片「黏」上去。晶片本身只有指甲蓋大小，腳位卻多到幾千個，間距極小，必須極度精準、散熱好、訊號傳輸快

什麼叫「高階板」

四個條件同時成立才叫高階：

  • 層數更多（常 10 層以上，甚至 20–40 層）
  • 線路更細
  • 孔更小（多數小於 0.1mm）
  • 材料更硬更貴

主要用在 AI 伺服器、旗艦手機、高階筆電、車用電子、5G 基地台。加工難在兩件事：

  • 孔超小、超多：一支板可能要打幾萬甚至十幾萬個極小的孔，孔要非常圓、位置要非常準，否則整塊板報廢
  • 板子又厚又硬：層數多、材料高階（含玻璃纖維、特殊樹脂），普通鑽頭打幾百個孔就磨損或斷掉

M9 是什麼？為什麼這麼難打孔

M9 不是「板子種類」，而是銅箔基板（CCL）材料的最高階規格（對標 Mitsubishi 的 M9 系列，或台 / 中系廠商同級材料）。它由三種高階材料組成：

  • Q 布（石英玻璃纖維布）：比普通玻璃布更純、更低損耗
  • 超低損耗樹脂（Df 通常 < 0.0013）
  • 極低輪廓銅箔（HVLP，Hyper Very Low Profile）

用在 NVIDIA Rubin 架構、GB200 後續高階 AI 伺服器、1.6T 交換器，目的是 224Gbps 以上的極高速傳輸減少訊號損失。

等級比喻
普通 PCB 材料一般馬路
M8高速公路
M9磁浮列車專用軌道——極致低損耗，但貴很多、加工極難

AI 伺服器需要同時傳超多高速訊號，普通 10–20 層不夠用，現在常做到 22–40 層以上（傳聞更高），搭 M9 才能維持訊號品質。

為什麼鑽針磨損這麼快

板材類型單支鑽針孔數加工難度原因
傳統普通多層板8,000–10,000 孔低材料軟、板薄
一般 HDI約 2,000 孔中孔徑小
M9 高階厚板僅約 200 孔極高石英布硬 + 板厚 + 精度要求高

四個原因疊在一起：

  1. 石英布很硬，像在硬石頭上打洞，會快速磨損鑽針的刃口和側面
  2. 板子又厚又多層，一次穿過很多層，熱量累積更多，鑽針承受的軸向力更大
  3. 孔徑要求精密，誤差容忍極小，容易產生孔壁粗糙、樹脂沾黏（smear）或鑽針偏斜
  4. 結果是鑽針磨損極快、容易斷

這就是為什麼業界特別強調「高階鍍膜鑽針」需求大增。

M9 vs HDI vs IC 載板：三件事互補不重複

很多人會把這三個名詞混在一起，但它們其實是不同維度的事：

項目M9高階 HDIIC 載板
本質材料（CCL 銅箔基板等級）製程技術（微孔結構）產品類型（晶片專用小板）
主要用途AI 伺服器高層數大板增加連接密度、縮小板子尺寸直接承載 CPU / GPU 等裸晶片
層數常 20–40 層以上可應用在高層數板上通常 4–12 層（但極細）
孔特色搭配微盲孔使用大量使用微盲孔、堆疊孔極細微孔 + 增層結構
材料硬度很硬（含石英 Q 布）看基材而定多用 ABF 膜材
在系統位置主機板、交換器板、背板應用在 M9 大板上晶片封裝內部

關係：晶片 → IC 載板 → M9 大板。三者互補，不互相取代。

AI 伺服器的三層結構

以 NVIDIA Rubin 架構為例，從晶片往外推像一棟大樓的三層結構：

層位置比喻技術
1最裡面（最靠晶片）頂樓的精密電梯間IC 載板：ABF 膜，特徵極細
2中間層大樓裡的快速電梯系統高階 HDI：微盲孔、堆疊微孔讓訊號上下層快速連接
3最外面（大板）整棟大樓的鋼骨 + 高級建材M9 多層板：層數非常多，搭 HDI 微孔，鑽孔難度極高

為什麼這三個一起出現？因為 AI 伺服器同時需要三件事：

  • 極高速傳輸 → 需要 M9 這種超低損耗材料
  • 極高連接密度 → 需要高階 HDI 的微孔技術
  • 晶片直接封裝 → 需要 IC 載板

微盲孔不是一次打完，是一層一層做出來的

堆疊微盲孔（Stacked Microvias）和交錯微盲孔（Staggered Microvias）採用循序增層製程。

英文叫 Sequential Build-Up / Any-Layer HDI。不是一次把所有孔打完，是一層一層做出來。以 6 層板為例：

  1. 先做內層核心（Core）：通常是 2 或 4 層的傳統板。用機械鑽孔打傳統通孔（Through Hole），然後電鍍
  2. 第一次增層（Build-up Layer 1）：上下兩面各壓合一層 Prepreg（半固化片）+ 銅箔。用雷射鑽孔（Laser Drilling）打微盲孔（只打到下一層，不穿透整塊板）。化學沉銅 + 電鍍，內壁鍍銅讓它導通
  3. 第二次增層（Build-up Layer 2）：再壓合新一層 Prepreg + 銅箔。雷射直接打在之前已鍍好的微盲孔正上方 → 堆疊微盲孔；若打在旁邊 → 交錯微盲孔
  4. 重複以上，直到達到所需層數
關鍵：每增加一層就要「壓合 → 雷射打微盲孔 → 電鍍」一次。電鍍是在每層打完孔後立刻做，不會被後面壓上的板子蓋住。

為什麼 M9 還是要用機械鑽，不能全部用雷射

高階 M9 板通常採用混合結構（Hybrid Construction），不是純 Any-Layer HDI。所以機械鑽孔還是會切到 M9：

情境為什麼還是要機械鑽
多核心壓合（Multi-Core）多塊較厚的 M9 Core 各自先做機械通孔，再疊起來壓合；壓合後仍要打貫穿多個 Core 的大通孔（電源、接地、低阻抗孔），這時機械鑽頭一次切多層 M9
最後階段的機械通孔連接器孔、安裝孔、測試孔、關鍵訊號孔——這些孔要貫穿整塊已含大量 M9 的厚板
高深寬比通孔AI 伺服器板很厚，某些通孔的深寬比很高；雷射打不了那麼深或那麼大的孔，必須用機械鑽頭從頭打到底

後段瓶頸：疊板數下降 + 孔壁品質

疊板數量大幅減少

普通板可以一次疊 3–4 片甚至更多一起鑽。M9 因為材料硬 + 孔徑小（尤其微孔）+ 精度要求高，通常只能單片或極少量疊板。結果是：

  • 機台稼動率下降
  • 整體產能受限
  • 單位成本上升

孔壁品質要求極高

AI 高速傳輸對孔壁非常敏感：

  • 孔壁必須光滑
  • 不能有樹脂沾黏
  • 後續電鍍要附著良好

M9 材料硬，切削時容易產生較多熱和纖維斷裂，孔壁品質控制難度比一般板高很多。

收束：投資角度的三條觀察線

  1. 高階鍍膜鑽針是 AI 伺服器產能瓶頸的「隱藏節點」——產能擴張遠慢於下游 AI 伺服器需求成長
  2. Union Tool + 台灣尖點（Topoint） 是少數能在 M9 板材上維持壽命與良率的供應商
  3. M9 + HDI + IC 載板三件事互補不取代——誰都不會被誰擠掉，需求一起被推高
